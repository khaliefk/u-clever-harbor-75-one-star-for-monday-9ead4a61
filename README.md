A one-star review of Monday, written as if Monday were a restaurant. One line, 21 words.

> One star. Monday sat me by the alarm clock, served cold coffee, and charged me for a weekend I never got.

## How it works

`main.py` writes that single line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). No network, no secrets, no dependencies.

## Run

```sh
python3 main.py
```
